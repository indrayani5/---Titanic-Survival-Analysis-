📘 Project Overview

This Power BI project analyzes the famous Titanic dataset to uncover key patterns behind passenger survival.
It provides interactive visual insights to understand which factors influenced survival rates, including gender, class, age, and embarkation location.

🎯 Objectives

Explore the relationship between passenger features and their survival outcome.

Identify the most influential factors affecting survival (e.g., gender, age, class).

Visualize the distribution of passengers and survival statistics using Power BI dashboards.

Demonstrate the use of data cleaning, transformation, and visualization techniques.

📊 Dashboard Features

Overview Page: Total passengers, survivors, and death counts.

Demographics Breakdown: Visuals by gender, age group, and passenger class.

Class-wise Analysis: Survival comparison among 1st, 2nd, and 3rd class passengers.

Embarkation Insights: Trends by port of embarkation (C, Q, S).

Interactive Filters: Dynamic slicers for exploring relationships between variables.

🧠 Tools & Technologies

Power BI – Data cleaning, modeling, and visualization

Excel / CSV – Data source

DAX (Data Analysis Expressions) – Calculated fields and measures

📁 File Included

Titanic Survival Analysis Dashboard.pbix → Power BI file containing the complete dashboard.

📌 How to Use

Download the .pbix file from this repository.


Open it in Power BI Desktop.

Explore the visuals using slicers and filters.
